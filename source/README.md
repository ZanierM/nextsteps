# Discover Uni files go here (once a year)

Upload these CSV files from the new Discover Uni download, then commit:

CONTINUATION, COURSELOCATION, EMPLOYMENT, ENTRY, GOSALARY, INSTITUTION, KISCOURSE,
LEO5, LOCATION, NSS, SBJ, TARIFF, TEFOutcome (all .csv), plus readme.txt.

Don't upload the XML file or the whole download folder. The "Rebuild university data"
Action then rebuilds the site's course data automatically.
